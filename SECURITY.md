# Security Policy

## Supported versions

Security fixes are released in the latest version of Xeonstrap only. Update to the [latest release](https://github.com/XeonCorporationOfficial/Xeonstrap/releases/latest) before reporting a problem.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Reporting a vulnerability

Do not report security problems in public issues, pull requests or Discord channels. Report them privately in whichever way you prefer:

* **GitHub:** [report a vulnerability](https://github.com/XeonCorporationOfficial/Xeonstrap/security/advisories/new) from the repository's **Security** tab.
* **Discord:** send a direct message to a Xeonstrap staff member on the [Discord server](https://discord.gg/wVFyshHUHh).

Include as much of this as you can:

* which app and version is affected (Windows or Android)
* what the problem is and what an attacker could do with it
* steps to reproduce it, or a proof of concept

## What to expect

You will get a reply once the report has been reviewed, and updates while a fix is worked on. Keep the details private until a fixed version is released. If you would like to be credited, say so in your report.

## Scope

This policy covers the Xeonstrap Windows and Android apps and the files published in this repository's releases.

Problems in Roblox itself belong to Roblox, so report them through the [Roblox bug bounty program](https://hackerone.com/roblox). Problems in a third party library belong to that project, but let us know too if Xeonstrap is affected.
